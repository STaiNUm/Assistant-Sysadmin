# Хранилище

Офлайн-приложение (PWA) для телефона: учёт сотрудников, оборудования и чего угодно
через настраиваемые «папки» с конструктором полей.

- Полностью офлайн: данные хранятся в браузере телефона (IndexedDB)
- Без сервера, без сборки, без зависимостей — чистые HTML/CSS/JS
- Резервные копии: Настройки → Экспорт/Импорт (JSON-файл)

## Структура

```
index.html            — оболочка
manifest.webmanifest  — манифест PWA
sw.js                 — service worker (офлайн-кэш)
css/style.css         — стили
js/db.js              — слой данных (IndexedDB)
js/ui.js              — UI-хелперы (DOM, модалки, тосты)
js/app.js             — роутер и экраны
icons/                — иконки (+ generate-icons.ps1 для пересоздания)
```

## Локальный запуск (для проверки на ПК)

Нужен любой статический сервер, например:

```
npx serve .
```

и открыть http://localhost:3000 (или порт, который покажет сервер).

## Установка на телефон через GitHub Pages

1. Заведите аккаунт на https://github.com (если его ещё нет).
2. Создайте новый репозиторий: кнопка **New repository**, любое имя
   (например, `khranilishche`), тип **Public**.
3. Загрузите в корень репозитория **все файлы из этой папки**
   (проще всего: на странице репозитория → **Add file → Upload files** →
   перетащить содержимое папки → **Commit changes**).
4. Откройте **Settings → Pages**, в разделе **Build and deployment** выберите:
   **Source: Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты приложение будет доступно по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`
6. Откройте этот адрес на телефоне в Chrome → меню **⋮** →
   **«Добавить на главный экран»**. Готово: дальше приложение работает офлайн.

## Обновление приложения

1. Загрузите изменённые файлы в репозиторий тем же способом.
2. **Важно:** перед загрузкой увеличьте номер версии в `sw.js`
   (строка `const VERSION = '1.0.0'` → `'1.0.1'` и т.д.) —
   иначе телефон не увидит обновление из-за кэша.
3. Откройте приложение на телефоне при включённой сети — обновление
   подтянется само.

## Данные

Все данные живут только в браузере устройства. При очистке данных браузера
или смене телефона они пропадут — поэтому регулярно делайте
**Настройки → Экспорт** и храните файл в надёжном месте.
