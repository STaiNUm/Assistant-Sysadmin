# Хранилище

Офлайн-приложение (PWA) для телефона: учёт чего угодно — сотрудников,
оборудования, инвентаря — через настраиваемые «хранилища» с конструктором полей.

- 📱 Рассчитано на телефон, работает полностью **офлайн**
- 🗂️ Своя структура для каждого хранилища: текст, число, дата, галочка,
  многострочный текст, выпадающий список
- 📁 Папки внутри хранилища любой глубины — чтобы разделять записи
  (например: Корпус А → 1 этаж → Принтеры)
- 📦 Перемещение записи между папками и на верхний уровень хранилища
- 🎨 Цвет хранилища, обязательные поля, поле-заголовок записи
- 🔍 Поиск и фильтр по списку (например, по местоположению) внутри текущей папки
- 🔒 Данные не покидают устройство: хранятся в браузере (IndexedDB)
- 💾 Резервные копии: экспорт/импорт одним JSON-файлом

Без сервера, без сборки, без зависимостей — чистые HTML/CSS/JS.

## Использовать готовое

Если кто-то уже развернул это приложение — просто откройте его ссылку
на телефоне в Chrome → меню **⋮** → **«Добавить на главный экран»**.
Дальше приложение работает офлайн.

## Развернуть свою копию (GitHub Pages, бесплатно)

1. Заведите аккаунт на https://github.com (если его ещё нет).
2. Создайте новый репозиторий: кнопка **New repository**, любое имя,
   тип **Public**.
3. Загрузите в корень репозитория **все файлы этого проекта**
   (на странице репозитория → **Add file → Upload files** →
   перетащить файлы → **Commit changes**).
4. Откройте **Settings → Pages** → **Source: Deploy from a branch**,
   ветка **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты приложение будет доступно по адресу:
   `https://<ваш-логин>.github.io/<имя-репозитория>/`
6. Откройте адрес на телефоне → **«Добавить на главный экран»**. Готово.

Подойдёт и любой другой статический хостинг (Vercel, Netlify, Cloudflare
Pages): все пути в приложении относительные, работает из любой подпапки.

## Локальный запуск (для разработки)

Нужен любой статический сервер, например:

```
npx serve .
```

и открыть адрес, который покажет сервер (обычно http://localhost:3000).

## Обновление уже установленного приложения

1. Загрузите изменённые файлы в репозиторий.
2. **Важно:** перед загрузкой увеличьте номер версии в `sw.js`
   (строка `const VERSION = '1.0.0'` → `'1.0.1'` и т.д.) —
   иначе устройства не увидят обновление из-за кэша.
3. Откройте приложение при включённой сети — обновление подтянется само.

## Данные и приватность

Все данные живут только в браузере устройства, на котором ведётся учёт.
При очистке данных браузера или смене устройства они пропадут — регулярно
делайте **Настройки → Экспорт** и храните JSON-файл в надёжном месте.
Восстановление: **Настройки → Импорт**.

## Структура проекта

```
index.html            — оболочка
manifest.webmanifest  — манифест PWA
sw.js                 — service worker (офлайн-кэш)
css/style.css         — стили
js/db.js              — слой данных (IndexedDB)
js/ui.js              — UI-хелперы (DOM, модалки, тосты)
js/app.js             — роутер и экраны
icons/                — иконки (+ generate-icons.ps1 для пересоздания)
```
